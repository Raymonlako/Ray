# Lido Deck Outbreak

A top-down zombie survival game set on the deck of a cruise ship at night. Open `index.html` in a browser; no build step.

- **WASD / arrows**: move · **Mouse**: aim the flashlight, click to shoot · **R** reload · **P** pause · **M** mute
- **Touch**: left thumb moves, right thumb aims and fires

Zombies climb out of the stairwell hatches and over the rails in waves: tourists, fast crew members and tough galley chefs. The pool slows everyone down. Buffet plates heal you; shotgun shells give you a spread shot.
